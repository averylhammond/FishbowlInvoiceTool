# What's New

Each release's changes, newest first. The application shows the sections you have not
seen yet the first time you open it after an update, and Help -> What's New brings this
back at any time.

## 4.2.1

- Maintenance release. Nothing about how the application works has changed.

## 4.2.0

- **See what changed after an update.** The application now opens with a summary of
  what's new the first time you start it after updating. Skip a release or two and you
  will see everything you missed, not just the newest version. Help -> What's New brings
  these notes back whenever you want them.

## 4.1.7

- **Update without leaving the application.** When a new version is available, the update
  window can now download and install it for you and reopen the application when it is
  done, instead of sending you to the download page. Exit and Update, which opens that
  page in your browser, is still there if you prefer it.
- Every download is checked against the checksum published with the release before it is
  run, so a partial or altered download is never installed.
- Your themes, fonts, edited configuration files and the invoices sitting in your
  Invoices folder all survive an update untouched.

## 4.0.2

- The application now closes itself once it has sent you to the download page, so the new
  version can replace it without asking you to close anything by hand.

## 4.0.1

- Added Help -> Open User Guide, which shows the bundled user guide in a window inside
  the application.

## 4.0.0

- **A rebuilt interface.** New look, a menu bar (File, Edit, View, Preferences, Help),
  selectable color themes and fonts, and an About window showing the version you are
  running.
- **Edit your configuration files in the application.** The Edit menu opens Cost Criteria,
  Payment Terms and Sales Reps in a built-in editor, and saving applies your changes
  right away -- no external text editor, no restart.
- **Add invoices without leaving the application.** The discovery window lets you pick
  downloaded invoice PDFs from a file browser and copies them into the Invoices folder
  for you.
- Added View -> Results Log, which opens the processing log in a window inside the
  application.
- Your theme, font and font size are now remembered and come back the way you left them.
- The application now checks for a newer version when it starts and tells you if one is
  available; Help -> Check for Updates runs the same check whenever you want it.
- Releases now include a setup wizard that puts the application in your Start menu, adds
  an optional desktop shortcut, and can be uninstalled like any other Windows program.
  Installing over an existing copy keeps your configuration files and invoices.
- Moved to a newer PDF library, so invoice reading stays supported going forward.
- Updated the user guide for the new interface and workflow.
